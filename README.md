# Мой тренер

PWA для набора мышечной массы: тренировки (верх/низ, 4 дня), дневник питания с КБЖУ, вес тела и прогресс в упражнениях.
Работает офлайн, ставится на телефон. Все данные хранятся только на устройстве (IndexedDB).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # проверить сборку (с сервис-воркером)
```

## Структура

```
src/
  main.tsx                 точка входа: инициализация БД, регистрация сервис-воркера
  App.tsx                  вкладки + нижняя навигация
  types.ts                 все типы данных
  db/
    db.ts                  схема Dexie (IndexedDB)
    init.ts                первичное заполнение: программа + база продуктов
    settings.ts            настройки и цели КБЖУ
  data/
    defaultProgram.ts      программа A/B/C/D
    foods.json             встроенная база продуктов (~400 шт., КБЖУ на 100 г)
  lib/                     чистая логика без UI
    workout.ts             прогрессия, прошлый результат, следующий день
    nutrition.ts           пересчёт КБЖУ, рецепты, поиск
    openFoodFacts.ts       онлайн-поиск и штрихкоды
    progress.ts            темп набора веса, графики упражнений
    backup.ts              экспорт/импорт JSON
  components/              общие UI-компоненты, таймер отдыха, навигация
  features/
    workouts/              тренировка, история, редактор программы
    nutrition/             дневник, выбор продукта, сканер, свои продукты, рецепты
    progress/              вес тела, графики, резервная копия
```

## Деплой

**Vercel:** импортируйте репозиторий на vercel.com → Framework: Vite → Deploy. Настраивать ничего не нужно.

**GitHub Pages:** запушьте в ветку `main`, затем Settings → Pages → Source: **GitHub Actions**.
Workflow `.github/workflows/deploy.yml` соберёт проект с `BASE_PATH=/<имя-репозитория>/`.
